# CafeOteca — Your Everyday Happy Place

A responsive restaurant website for CafeOteca in Dafi, Varanasi.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — menu filtering, cart and WhatsApp ordering

## Run locally
Open `index.html` in a browser. No build tools or backend are required.

## WhatsApp ordering
The order builder uses WhatsApp number `+91 93352 24704`. Customers select menu items, review the estimated total, then open WhatsApp with the order message prefilled. The customer must press Send in WhatsApp to submit it.

## Deploy
Enable GitHub Pages for the `main` branch, root folder, or connect this repository to a static hosting provider such as Vercel or Netlify.
